# Changelog — MeAlembra

All notable changes to this project will be documented in this file.

## [Unreleased]

### Added
- FastAPI backend.
- SQLite database integration.
- Task creation, listing, updating and deletion.
- Task completion and rescheduling.
- Notification configuration associated with reminders.
- Persistent notification interval set to 15 minutes by default.
- APScheduler background scheduling.
- Initial frontend structure using HTML, CSS and JavaScript.
- Four customizable visual themes: pink, blue, gray and beige.

### Changed
- Updated the application identity to a soft and minimal visual style.
- Removed personal imagery to support a multi-user product identity.

### Planned
- Real Web Push notifications.
- Progressive Web App functionality.
- Task history and frequently created task detection.
- Regular tasks management.
- User-specific preferences.
- Calendar and statistics views.
